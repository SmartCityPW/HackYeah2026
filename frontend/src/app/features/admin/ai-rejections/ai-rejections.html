Agent się pomylił? Dopisz przypadek do zestawu regresyjnego

Wpis z numerem ze stopki trafia do config/moderation_cases.yaml, a moderation_eval sprawdza wtedy, czy zmiana promptu go naprawiła:

python manage.py moderation_log_to_cases <numer> --expect approve

Użyj --expect reject, gdy odrzucenie było słuszne i chcesz je utrwalić albo gdy agent przepuścił atak.
